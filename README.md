# 本草簿

一个无需构建步骤的中药学课堂检索与记忆工具。

## 使用

直接打开 `index.html` 即可。页面支持药名、拼音、功效和归经搜索，按功效分类、药性与详录状态筛选，并提供本地收藏、随机识药和随堂测验。

药材图片通过南京中医药大学中药标本中心的公开标本图优先匹配（当前已整理 212 味），其余条目按需回退到维基百科摘要接口；没有网络或条目无图时，页面会自动显示药名首字作为回退。详情页会保留图片来源链接。

## 数据说明

`herbs.js` 包含 200–300 味课堂索引数据。标记为“详录”的条目具有较完整字段，其余条目仅提供分类记忆提示。内容仅用于学习，不构成诊断、处方或用药建议。
